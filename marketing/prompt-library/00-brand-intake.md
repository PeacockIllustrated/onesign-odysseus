# 00 · Brand Intake

Everything in this file is **meant to change per brand** — this is the style layer. Fill it in
before writing a single scene. The other modules (engineering, QA) stay constant; this one is
where a new brand gets its own identity so two reels can look nothing alike yet feel equally
finished.

## Answer these first (the open questions)

1. **Brand + product.** What is the brand, and what single thing is the reel selling?
2. **Hero object.** What is on screen at the "money shot"? (For the seed reel it was a folded-
   aluminium sign. For a new brand it might be a product, an app UI, a packshot, a typographic
   lockup — decide the ONE thing the film builds toward.)
3. **Platform + length.** Reel/TikTok (9:16, ~15–35s) is the default; confirm.
4. **Feel — 3 adjectives.** e.g. "warm, editorial, calm" vs "loud, neon, kinetic". This dictates
   motion and type more than colour does.
5. **Sound-off?** Almost always yes for social — captions must carry the story.

## Guardrail

The seed reel's specifics — teal `#4e7e8c`, Anton+Gilroy, folded-aluminium panel, day→night sign
glow — are **that brand's** answers to the questions above, not defaults. Re-derive every value
here for the new brand. If a value ends up matching the seed reel, it should be a deliberate
choice, not an inheritance.
